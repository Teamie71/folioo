# 웹 Figma 기준

웹 UI 작업의 Figma 기준은 PC와 모바일의 아래 두 페이지다. 해당 페이지 안에서 대상 프레임을 열고 필요한 상태와 기기별 배치를 확인한다. 정책 페이지 세 화면은 아래에 명시한 예외를 적용한다.

| 구분   | 현재 기준      | Figma                                                                                      |
| ------ | -------------- | ------------------------------------------------------------------------------------------ |
| PC     | `v.3.9 (최신)` | [PC 시안 열기](https://www.figma.com/design/l3NWpGaPsOj5KYgt9b5hxN/?node-id=11556-1798)    |
| 모바일 | `신 모바일`    | [모바일 시안 열기](https://www.figma.com/design/l3NWpGaPsOj5KYgt9b5hxN/?node-id=10286-360) |

## 작업 시안 선택

- Jira에 프레임 링크가 있으면 해당 기기의 기준 페이지에 속하는지 확인한다. 정책 페이지는 아래 예외 표에서 선택한다.
- 기준 페이지에서 대상 화면이나 상태를 찾을 수 없거나 Figma에 접근할 수 없으면 확인이 필요한 범위를 Jira에 남긴다.
- 이관에서는 Figma로 의도된 UI를 확인하고 레거시로 기존 동작과 진입 경로를 확인한다. 시안·레거시·토큰 사이에 차이가 있으면 [UI 구현 가이드의 토큰 예외 처리](./ui-implementation.md#토큰-예외-처리)를 따른다.

## 기준 버전 갱신

1. 새 Figma 버전을 웹 작업에 적용하기로 결정하면 문서 첫 표에서 해당 기기의 버전·페이지 링크를 갱신한다. 새 페이지나 새 파일로 옮겨간 경우도 같은 방식으로 관리한다.
2. 정책 페이지는 새 시안을 적용하기로 결정했을 때 예외 표의 해당 프레임을 갱신한다.
3. 진행 중인 Jira는 시작할 때 합의한 시안을 사용한다. 새 버전을 적용하기로 했다면 해당 Jira에 바뀐 프레임 링크와 영향을 받는 화면·상태를 남긴다. 이후 시작하는 작업은 갱신된 기본 기준을 따른다.
